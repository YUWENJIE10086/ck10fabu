## 📄 PPT内容：常态运维——烤房健康分与寿命预测
### 一、指标体系（5大部件 × 20+项细分指标）
| 部件 | 权重 | 子部件（二级指标） |
|------|------|-------------------|
| JR 加热设备 | 30% | 燃烧机(burner)、风机(fan)、电机(motor) |
| SR 散热器 | 26% | 管道(pipe)、炉体(furnace)、灰门(ash_door)、烟囱(chimney) |
| ZK 自控设备 | 26% | 探针(probe)、控制器(controller)、水壶(water_pot)等8个子部件 |

> **数据来源**：kf_heater、kf_radiator、kf_controller、kf_oven_body四张表，全来自YC内部巡检台账
### 二、算法流程（六步走，逐层递进）
```
┌─────────────────────────────────────────────────────────────┐
│ Step 1  数据采集与血缘校验                                 │
│ ├─ 低代码手机采集：经纬相机拍照+部件状态评分录入            │
│ ├─ 血缘融合模型：自动追踪烤房-部件-维修记录关联关系         │
│ └─ 异常检测：3σ原则剔除异常值，校验数据一致性              │
│             （适用算法：孤立森林 / 箱线图法）               │
├─────────────────────────────────────────────────────────────┤
│ Step 2  部件健康评分（三维量化）                           │
│ ├─ 状态分 S_status：正常=100，异常=50，损坏=0              │
│ ├─ 退化分 S_degrade：基于CDCI三段式退化函数计算             │
│ ├─ 评价分 S_eval：较好=80，一般=60，较差=50，差=30         │
│ └─ 部件得分 C_i = α×S_status + β×S_degrade + γ×S_eval     │
│             α=0.4, β=0.3, γ=0.3                            │
├─────────────────────────────────────────────────────────────┤
│ Step 3  退化曲线计算（CDCI三段式退化函数）                  │
│ ├─ 稳定期（Δt ≤ 0.2L）：h(Δt)=100                         │
│ ├─ 线性退化期（0.2L < Δt ≤ 0.7L）：h=100-k₁×(Δt-0.2L)    │
│ ├─ 加速劣化期（Δt > 0.7L）：h=30×e^(-k₂×(Δt-0.7L))        │
│ └─ 不同部件差异化额定寿命L（燃烧机8年/风机6年/墙体15年…）  │
│             （适用算法：非线性回归 / 分段函数拟合）          │
├─────────────────────────────────────────────────────────────┤
│ Step 4  综合健康分（加权汇总）                              │
│ └─ HealthScore = W_JR×C_JR + W_SR×C_SR + W_ZK×C_ZK + W_ZT×C_ZT │
│             → 0-100分制                                     │
│             （适用算法：加权算术平均 / AHP确定的固定权重）    │
├─────────────────────────────────────────────────────────────┤
│ Step 5  寿命预测（BDRL双段退化模型）                        │
│ ├─ 前段线性退化：H(t) = 100 - k₁·t（0 ~ T_c）              │
│ ├─ 后段加速劣化：H(t) = H_c·[1-((t-T_c)/(T_end-T_c))²]     │
│ ├─ 维修回弹效应：每8年一次大修，延寿3年                     │
│ └─ 输出：剩余寿命（年）+ 维修预警时间                       │
│             （适用算法：BDRL / 维纳过程 / 灰色预测GM(1,1)）  │
├─────────────────────────────────────────────────────────────┤
│ Step 6  分级预警与维修决策                                  │
│ ├─ 随机森林分类器：基于历史健康分训练，自动识别预警等级     │
│ ├─ 维修优先级排序：健康分越低、剩余寿命越短 → 排名越靠前    │
│ └─ 自动推送：触达阈值 → 生成维修工单 → 推送至相关人员       │
│             （适用算法：随机森林 / XGBoost / 决策树）        │
└─────────────────────────────────────────────────────────────┘
```
### 三、预警分级（5级管控）
| 健康分范围 | 剩余寿命 | 等级 | 颜色 | 响应动作 |
|-----------|---------|------|------|---------|
| ≥ 90分 | > 8年 | 优良 | 🟢 | 常规巡检，年度保养 |
| 75 ~ 90分 | 5~8年 | 良好 | 🟢 | 季度巡检，重点关注 |
| 60 ~ 75分 | 3~5年 | 一般 | 🟡 | 加强监测，列入维修计划 |
| 40 ~ 60分 | 1~3年 | 预警 | 🟠 | 触发维修预警，3个月内安排维修 |
| < 40分 | ≤ 1年 | 危险 | 🔴 | 立即停用，优先更换/大修 |
> **自适应阈值**：每季度根据全县烤房健康分布，动态调整红黄蓝分界点，避免标准僵化
### 四、算法选型逻辑（为什么这么搭？）
| 步骤 | 选用算法 | 理由 |
|------|----------|------|
| 数据校验 | **血缘融合模型** | 自动追踪烤房-部件-维修记录关联，发现异常填报（如修复年份晚于建成年份），提升数据质量 |
| 部件权重 | **AHP层次分析法** | 专家判断确定4大部件权重（JR 30%/SR 26%/ZK 26%/ZT 18%），符合烟草行业实际 |
| 退化计算 | **CDCI三段式函数** | 分段拟合更贴近真实老化规律（稳定→线性→加速），优于简单线性衰减 |
| 寿命预测 | **BDRL双段退化** | 行业首创，融合维修回弹效应，可解释性强，预测误差＜15% |
| 预警分类 | **随机森林** | 处理非线性关系，特征重要性可解释，适合小样本场景，准确率稳定 |
| 异常检测 | **孤立森林** | 高效识别异常健康分/异常房龄组合，自动标记需人工复核的烤房 |
