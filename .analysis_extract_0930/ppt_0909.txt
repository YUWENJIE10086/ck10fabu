模型 ①
健康评估 —— 树状拆解到每一分
H = 0.80·P总部件分 + 0.10·M管护分 + 0.10·E人工分（0~100）
① 总部件分 P = Σ( Wᵢ × scoreᵢ ) / ΣWᵢ × 100　　（ΣWᵢ = 80）
每个部件 scoreᵢ = 100 × ( 0.50×S_status + 0.35×R_remain + 0.15×C_eval )
S_status 状态
正常1.0 ·一一般0.7 · 损坏0.3 · 缺失
R_remain  寿命比
剩余年限 ÷ 指导寿命（修复年→回春归零）
C_eval 评价
好1.0 · 差0.5 · 缺省0.8
② 管护分 M ×0.10
集中100 · 分户80
③ 人工分 E ×0.10
好100 · 中80 · 差50
贡献 Cᵢ = Wᵢ×scoreᵢ÷100　　健康状况五档：≥90优良 / ≥75良好 / ≥60一般 / ≥40预警 / <40危险

===== SLIDE 2 =====
模型 ②
剩余寿命 —— 五层递进到"几年"
左：五层公式树（怎么算）　右：2009老房保养算例（维修能续命·不能回春）
life = clamp( life_raw , 0 , year_cap )
life_raw = ( hard_limit×0.6 + soft_avg×0.4 )×repair_decay×health_factor
A类 硬上限　×0.6
hard_limit = min(屋顶, 大门, 挂烟梁) 最短寿命
结构性定“生死上限”
B类 软平均　×0.4
soft_avg = Σ(寿命×重要度) ÷ Σ重要度
功能性定“运行质量”
维修 复衰　e^衰减
repair_decay = e^(−0.08×维修次数)
修1次0.92 · 修3次0.79
健康 校准　加速
health_factor = 0.70 + 0.30×(H/100)
H=100→1.00 · H=40→0.82
L5 年限收缩+钳制：year_cap = max(0, 15−房龄×0.55)，老房不虚高、新+2.65封顶
四级预警：≤0紧急 · 1~4建议维修 · 4~7需关注 · >7正常
单栋算例 · 2009老房（2022换自控·2024修散热, H=71）
L1 硬上限
屋顶最弱 → hard_limit = 2.5年
L2 软平均
soft_avg = 5.0 年（9功能件加权均值）
L3 维修复衰
修2次 → e^(−0.16) = 0.852
L4 健康校准
H=71 → 0.70+0.30×0.71 = 0.913
life_raw
(2.5×0.65+5×0.35)×0.852×0.913 = 2.63
L5 年限收缩
year_cap = 15−17×0.55 = 5.65
life = clamp(2.63, 0, 5.65) = 2.6 年
→ 建议维修（1~4年）· 退役年≈2029
维修能续命但不能回春：老房即使换新设备，也被年限收缩约束

===== SLIDE 3 =====
模型 ③
村级发展指数 —— 三维度算到"建几座"
左：三维度公式树（怎么算）　右：一个千亩村算到底（算给评委看）
V = 0.50·Hc + 0.30·Lc + 0.20·Dc　新建需求分 N = 100 − V
Hc 有效烤能指数 ×0.50
单栋 E=健康分/100×容量×状态(在用1.0·闲置0.4·待修0.1)
A=在用ΣE ， B=闲置ΣE×0.4 ， C=待修ΣE×0.1
Q=0.7A+0.2B+0.1C ， Hc=min(100, Q/D×100)
Lc 承载匹配指数 ×0.30
压力 P = D ÷ Q · 分档：≤0.85→100 · ≤1→85 · ≤1.2→70 · ≤1.5→50 · >1.5→30
Dc 发展因子指数 ×0.20
五维各0.2：规模增长 · 管护缴费 · 政策争取 · 服务能力 · 扩张韧性 → Dc=五维均值
决策：V越低→烤能缺口越大→新建越迫切　N越高→优先级越高
单村算例（10 座烤房）  容量50担/座 · 理论需求 D=450担
在用7座·烤房健康均分约80分
A = 7×80/100×50 = 280
闲置2座·烤房健康均分65分
B = 2×65×50×0.4/100 = 26
待修1座·烤房健康均分45分
C = 1×45×50×0.1/100 = 2.25
Q
0.7×280+0.2×26+0.1×2.25 = 201.43担
Hc
201.43/450×100 = 44.8
P
450/201.43 = 2.23 → Lc = 30(严重不足)
Dc
(85+80+70+75+40)/5 = 70
V = 0.5×44.8 + 0.3×30 + 0.2×70 = 45.4
→ N = 54.6
建议优先配建约5座 · 新增后再算 ΔV 检验是否值得建
