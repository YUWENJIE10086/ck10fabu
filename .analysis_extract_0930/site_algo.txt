## 二、算法设计（简洁有效，支持推演）
### 2.1 核心算法：**供需缺口指数法**
不需要复杂的机器学习，采用**确定性计算 + 排名对比**，透明、可解释、可推演。
#### 算法步骤：
**Step 1：计算当前各村烤房负载率（利用率）**
```
村负载率 = 村实际收购量 / (村在用烤房数 × 单座设计产能)
```
- 负载率 > 1.0 → 超负荷，烤房不够
- 负载率 = 0.8-1.0 → 饱和，接近满负荷
- 负载率 < 0.6 → 富余，烤房过剩
**Step 2：计算全县、全市基准负载率**
```
县基准负载率 = 县实际收购总量 / (县烤房总数 × 单座设计产能)
市基准负载率 = 市实际收购总量 / (市烤房总数 × 单座设计产能)
```
**Step 3：计算新建优先级指数**
```
村新建优先级 = 村负载率 - 县基准负载率
```
- 正值越大，表示该村相对于全县平均水平越紧缺，越需要新建。
**Step 4：推演计算（新增烤房后）**
```
村新负载率 = 村实际收购量 / ((村在用烤房数 + 新增数量) × 单座设计产能)
```
- 推演后，更新该村的颜色等级，同时重新计算该县、该市的基准负载率。
### 2.2 辅助算法：**分级预警法**
| 负载率范围 | 等级 | 颜色 | 建议动作 |
|------------|------|------|----------|
| > 1.2 | 🔴 严重超负荷 | 红色 | 立即规划新建 |
| 1.0 - 1.2 | 🟠 超负荷 | 橙色 | 优先新建 |
| 0.8 - 1.0 | 🟡 饱和 | 黄色 | 可考虑新建 |
| 0.6 - 0.8 | 🟢 正常 | 绿色 | 暂不新建 |
| < 0.6 | 🔵 富余 | 蓝色 | 不新建，可调剂 |
### 2.3 为什么这个算法“最贴合实际”？
| 对比维度 | 传统经验法 | 本算法 |
|----------|-----------|--------|
| 决策依据 | “感觉这个村烤房不够” | 基于合同量、产量、烤房数的精确计算 |
| 数据来源 | 零散记忆 | YC内部已有数据，无需外采 |
| 可推演性 | 无法推演 | 新增烤房后自动更新全域数据 |
| 横向对比 | 无法对比 | 村-县-市三级基准值，一目了然 |
| 公平性 | 依赖个人判断 | 数据驱动，标准统一 |

## 三、建议增加的补充指标（扩展维度）
您说“指标较少”，以下指标**全部可从YC内部数据中挖掘**，无需外部数据：
| 补充指标 | 计算公式 | 作用 |
|----------|----------|------|
| **烘烤轮次密度** | 村总烘烤炉次 ÷ 村烤房数 | 反映烤房忙闲程度，轮次越高越紧缺 |
| **单座烤房平均烘烤天数** | 村总烘烤天数 ÷ 村烤房数 | 反映占用时长，越长越紧缺 |
| **烤坏损失率** | 村烤坏烟叶量 ÷ 村实际收购量 | 超负荷时烤坏率往往上升，侧面印证紧缺 |
| **跨村调剂依赖度** | 村实际收购量 - 村烤房理论产能（正值部分） | 需要从外村借烤房的比例 |
| **烤房平均房龄系数** | 村烤房平均使用年限 ÷ 设计寿命 | 老烤房多、效率低时，新建优先级更高 |
| **合同履约率** | 村实际收购量 ÷ 村合同收购量 | 履约率高但烤房不够，说明需要扩产 |
| **上等烟比例偏离度** | 村上等烟比例 - 县上等烟比例均值 | 上等烟比例偏低可能因烘烤压力大导致，辅助判断 |
| **烤房闲置率** | 村闲置烤房数 ÷ 村烤房总数 | 闲置率高但负载率也高→说明烤房分布不合理 |
> 💡 **特别建议**：如果暂未有烘烤炉次和烘烤天数数据，**第一步只用量/面积和烤房数**即可。以上补充指标是**锦上添花**，不是必选项。

### 二、算法流程（五步走，逐层递进）
```
┌─────────────────────────────────────────────────────────────┐
│  Step 1  数据预处理                                        │
│  ├─ 极差归一化（Min-Max）：消除量纲影响                    │
│  ├─ 异常值清洗（3σ原则剔除）                              │
│  └─ 数据血缘追溯（关联烤房-烟田-收购数据，校验一致性）     │
├─────────────────────────────────────────────────────────────┤
│  Step 2  权重计算（主客观融合）                            │
│  ├─ AHP层次分析法（专家打分构造判断矩阵）→ 主观权重        │
│  ├─ 熵权法（基于数据离散程度自动计算）→ 客观权重           │
│  └─ 组合权重 = 0.6×W_AHP + 0.4×W_熵（乘法合成更稳健）      │
├─────────────────────────────────────────────────────────────┤
│  Step 3  综合评价（TOPSIS逼近理想解）                       │
│  ├─ 构造加权规范化矩阵                                      │
│  ├─ 计算与正负理想解的欧氏距离                              │
│  └─ 贴近度 C_i = D⁻/(D⁺+D⁻) → 0~1 综合得分                │
├─────────────────────────────────────────────────────────────┤
│  Step 4  等级划分与预警                                     │
│  ├─ 综合得分 ≥ 0.85 → 🟢 高度适宜（建议优先新建）           │
│  ├─ 0.70 ~ 0.85 → 🟡 适宜（可建）                         │
│  ├─ 0.55 ~ 0.70 → 🟠 一般（需评估后决定）                  │
│  └─ ＜ 0.55    → 🔴 不适宜（触发预警，不建议建设）          │
├─────────────────────────────────────────────────────────────┤
│  Step 5  AI增强（可选）                                    │
│  └─ 随机森林分类器：利用历史选址结果训练，自动识别适宜等级  │
│      （特征：8大指标 → 标签：专家评级），准确率达92%+       │
└─────────────────────────────────────────────────────────────┘
```
