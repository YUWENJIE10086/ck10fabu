📊 健康分 · 分项拆解 （部件80% + 管护10% + 人工10%）

🔩 部件归一化健康分 P_norm

// 12个部件逐项打分，加权归一 P_norm = Σ( Wᵢ × scoreᵢ ) / ΣWᵢ × 100 ΣWᵢ = 80（固定总权重） scoreᵢ = 100 × ( 0.50×S_status + 0.35×R_remain + 0.15×C_eval ) S_status : 状态系数（正常1.0 · 异常0.7 · 损坏0.3 · 缺失0） R_remain : 剩余寿命比 = 剩余年限 / 指导寿命 C_eval : 评价系数（优良/好=1.0 · 差=0.5 · 缺省=0.8）

⏳ 剩余寿命 · 分项拆解 （五层递进计算）

🧱 第1层：A类硬上限

hard_limit = min( roof_life, door_life, beam_life ) // A类部件（结构性）最短剩余寿命 // 屋顶/墙体、大门、挂烟梁柱 —— 三者任一损坏，整栋报废

📌 硬上限决定烤房“还能不能撑”

⚙️ 第2层：B类软平均

soft_avg = Σ(B类寿命 × 重要度) / Σ重要度 // 9个功能件按重要度加权平均 // 重要度系数：自控1.25 · 加热1.15 · 散热1.05~1.10 · 风机1.00

📌 软平均决定烤房“好不好用”

🔧 第3层：维修复衰

repair_decay = exp( -0.08 × total_repair_count ) // 维修次数越多，可靠性逐次递减 // 修1次 → 0.923 · 修3次 → 0.786

📌 “越修越不靠谱”效应

📉 第4层：健康校准

health_factor = 0.70 + 0.30 × ( H / 100 ) // 健康分低 → 寿命加速衰减（指数型） // H=100 → 1.00 · H=60 → 0.88 · H=40 → 0.82

📌 威布尔型加速因子

⏳ 第5层：年限收缩 新增 · 关键修正

year_cap = max( 0, 15 − (当前年 − 建成年) × 0.55 ) // 建成年限越久，理论寿命上限越低 // 2025年新建 → 上限14.45年 · 2009年老房 → 上限5.65年

📌 核心作用：A类结构性部件的物理老化无法通过维修逆转，年限收缩确保老房即使换了新设备，寿命也不会被高估。

🧮 最终合成（第6步）
life = clamp( ( hard_limit × 0.65 + soft_avg × 0.35 ) × repair_decay × health_factor , 0 , year_cap )

正常 >7年  ·  需关注 4~7年  ·  建议维修 1~4年  ·  紧急维修 ≤0年
