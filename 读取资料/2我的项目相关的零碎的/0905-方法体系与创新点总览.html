创新主线

把上面每一个拍脑袋环节，替换成一个有名、有数学背书的方法——不是推翻计算，而是让每个环节都"说得清为什么这样"。

定权区 把"拍的权重"升级成"科学定权"——AHP + 熵权组合

AHP 层次分析法★★★★★ 最有名
用途：给健康分 80/10/10、发展指数 50/30/20 重新科学定权
① 同一层指标两两比较打 1–9 分 → 判断矩阵 A ② 求最大特征值 λmax 对应特征向量 → 归一化即权重 w ③ 一致性检验：CI=(λmax−n)/(n−1)，CR=CI/RI < 0.1 通过
🗣 "健康分这三个维度 80/10/10 不是拍出来的，是 AHP 两两比较打分、通过了一致性检验算出来的。"
熵权法 + AHP-熵权组合赋权★★★★★ 高光
用途：提供客观权重，与 AHP 主观权重合并，双校验
指标信息熵 e_j = −(1/ln n) Σ p_ij·ln p_ij 客观权重 w_j = (1−e_j) / Σ(1−e_j) // 数据离散度越大权重越高 组合赋权 W积 = w主观^α · w客观^(1−α) // 乘法归一，α∈[0,1]
🗣 "我们既有人对业务的理解（AHP），又有数据自己的意见（熵权），两套权重一比对——如果对着，说明客观规律支持业务判断；要是对着我们是错的，我们也会亮出来改。"

好处：从"老师教什么就是什么"变成"老师 + 数据互相背书"。这是最容易让评委点头的"科学性"提升点。

寿命区 把"公式外推"升级成"可靠性建模说真话"——威布尔 / 生存分析 / 灰色 GM

威布尔分布★★★★★ 可靠性金标准
用途：逐部件寿命分布建模，直接输出"用 N 年可靠度 90%"
可靠度 R(t) = e^( −(t/η)^β ) η 尺度参数、β 形状参数(老化类型)： β<1 早期失效 · β=1 随机失效 · β>1 老化损耗
🗣 "我们不只回答'还能用几年'，还回答'用 3 年可靠度还有 92%'——这是可靠性工程的标准语言。"
生存分析★★★★★ 高光
用途：用真实维修/报废时间画生存曲线，找寿命影响因素（Cox）
Kaplan-Meier 生存曲线：S(t)=∏(1 − d_j/n_j) Cox 风险回归：h(t)=h₀(t)·e^(β₁X₁+…+βₖXₖ) → 输出"某因素每提升一档，寿命风险升高/降低多少"
🗣 "我们把维修台账当'真实事件数据'来用——哪个部件几年后坏、坏前修了几次，生存曲线里全看得见，不用一条造假数据。"
灰色预测 GM(1,1)★★★★ 小样本正解
用途：替代 LSTM 的诚实之选——几组数据就能预测寿命/规模趋势
原始序列 x(0) → 累加生成 x(1) 建立白化微分方程 dx(1)/dt + a·x(1) = b 解出预测式：x̂(1)(k+1) = (x(0)(1) − b/a)·e^(−ak) + b/a 后验差比 C 校验精度
🗣 "我们数据量不大，所以时序预测用灰色系统理论——它专为小样本预测而生，比硬上大数据模型更诚实、也更稳。"
为什么这套"替代 LSTM"更聪明

LSTM 需要海量逐日/逐月时序数据，而咱只有年粒度 + 台账。威布尔/生存分析把数据当成可靠性工程事件用，GM(1,1) 天生小样本——三者都不需要造假造大数据，且全部有名、有教科书、评审问不倒。

预警区 把"拍 Top3"升级成工程级风险排——FMEA / 帕累托

FMEA 失效模式与影响分析★★★★★ 工程圈公认
用途：替换"风险缺口 Top3"，每个部件给风险优先数 RPN
每个部件三张分（1–10）： 严重度 S × 发生频度 O × 可探测度 D 风险优先数 RPN = S × O × D → 从大到小排序 （对应现行 Kᵢ 风险加权：Gapᵢ × 自控1.25/加热1.15…可映射上）
🗣 "我们不说'这部件看着重要'，而是每个部件算了 FMEA 的风险优先数（严重度×发生×探测），谁的 RPN 高就先修谁——这是汽车、装备行业的标准做法。"
帕累托 ABC 分析★★★★ 二八定律
用途：维修派工——20% 部件贡献 80% 风险
按 RPN 降序累计占比： A 类(累≤80%) → 重点优先维修 B 类(80–95%) → 次重点 C 类(95–100%) → 日常巡检
🗣 "我们先让 FMEA 算出风险，再用帕累托告诉您：把力量集中在 A 类那 20% 部件上，就解决 80% 的问题。"

决策区 把排序与选址升级成真方法——TOPSIS / 区位熵 / 最大覆盖 / MILP

TOPSIS 逼近理想解法★★★★★ 有名
用途：村级新建排序、烟农画像排序
① 归一化指标矩阵 ② 找正理想解 Z+（每项最优）与负理想解 Z−（每项最差） ③ 贴进度 Cᵢ = D⁻ / (D⁺ + D⁻) → Cᵢ 越大越优，排序
🗣 "我们排第一的村，不只是 50/30/20 加出来的，而是离'理想村庄'最近、离'最差村庄'最远——TOPSIS 是公认的多准则排序法。"
区位熵 LQ★★★★★ 判"够不够"
用途：客观判断某村烤房相对全县是紧张还是富余
LQ = (村烤房密度 / 村烟叶需求) / (全县烤房密度 / 全县烟叶需求) LQ > 1 → 相对充足 · LQ < 1 → 相对不足
🗣 "我们先用区位熵回答'这村烤房是真缺还是假缺'，避免拿钱到处乱建。"
最大覆盖选址★★★★ 怎么建最划算
用途：让新建烤房尽量覆盖更多烟农
在给定要建栋数下： max Σ 被覆盖的烟农需求量 s.t. 每栋容量 ∈ 可选容量档 · 位置可达距离约束
🗣 "我们在需求最集中的位置优先建，让每栋新烤房覆盖最多的烟农户。"
整数规划 MILP★★★★★ 高光
用途：在预算×栋数×容量约束下给出最优补建方案
目标：min 总成本 或 max 覆盖缺口 约束：Σ 栋数 ≤ 预算可用 · Σ 容量 ≤ 容量上限 每栋是否为选 yᵢ ∈ {0,1} 求解：分支定界 → "建哪几栋、每栋多大"最优解
🗣 "现在的'推荐新建栋数'以前靠估，现在用整数规划在预算约束里算出的，是可执行、可说明的最优方案。"
