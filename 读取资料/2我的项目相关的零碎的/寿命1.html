🔧 升级寿命预测 · 基于最新健康分

烤房剩余寿命：从“整栋一个数”到“逐部件短板融合”

本方案将寿命预测从仅依赖整栋健康分反推，升级为逐部件计算剩余年限 + 短板约束。 我们详细解释每一步的“为什么”——包括退化曲线选择、维修重置、数据兜底，以及最终如何合成整栋剩余寿命。

一、现有寿命预测（BDRL）的工作原理

当前系统默认使用“最终版 BDRL”（双段退化）。它的核心是：用整栋烤房的健康分 health_score_final 反推一个“等效健康年龄”，再外推到失效阈值，得到剩余寿命。

📌 核心思路

  • 输入：建设年份、当前健康分（0~100）。
  • 假设：烤房健康退化先线性（稳定期），后加速（劣化期）。
  • 转折点：8年时健康分降至60，理论寿命终点12年，失效阈值40分。
  • 维修延寿：每修一次，理论终点延长2.5年。

📉 曲线形状

前段（0～8年）：健康分 = 100 – 5×房龄 后段（8年后）：健康分 = 60 × [1 – ((房龄–8)/(理论终点–8))²]

然后用实际健康分与理论值比较，若实际更高，则按比例延长剩余寿命。

✅ 优点：不再按物理年龄一刀切，老房若维护好也能延寿。
❌ 不足：只看整栋平均分，掩盖了“自控仪6年就坏、烟夹5年老化”这类部件级差异，无法回答“具体该修哪个部件”。

二、升级方案：逐部件预测 + 短板约束

每一栋烤房由多个部件组成，每个部件有自己的指导寿命、修复记录、当前状态。 真正的寿命瓶颈，往往是最先到期的那个部件。我们把每个部件的剩余年限算出来，再合成整栋寿命。

🔹 部件层（L1）

对每个主要部件（加热器、散热管、自控仪、主体等）：

  • 读取其指导使用年限（如自控仪6年，散热管15年）。
  • 计算已用年限 = 当前年份 – max(部件修复年份, 该部件最近维修完工年份)。
  • 结合状态系数（正常/异常/损坏/缺失）进行修正。
  • 加上维修激励（每修一次额外延长一定年限）。
  • 得出该部件剩余年限。

🔹 整栋合成（L2）

用两种视角融合：

  • 短板约束：最脆弱的部件决定整栋下限（权重60%）。
  • 部位整体水平：四大部位（加热/散热/自控/主体）加权平均（权重40%）。
  • 同时保留现有BDRL结果作为宏观校验（权重α可调，默认0.5）。
  • 最后加入人工评价修正（好/中/差），作为现场复核的留口。

三、部件退化曲线：为什么选用“双段式”

设备老化通常不是匀速的：早期稳定，后期加速。比如自控仪前3年故障率低，5年后急剧上升。 为此我们采用双段退化曲线，与健康分中的CDCI曲线同源，但直接用于“剩余年限”计算。

📈 曲线公式（用于部件剩余年限）

已用年限 A = 今年 – 修复/建成年份 指导寿命 T（查表） 若 A ≤ 0.2T → 稳定期，剩余 = T–A（无衰减） 若 0.2T < A ≤ 0.7T → 线性衰减，剩余 = (T–A) × (0.7 – A/T)/0.5 若 A > 0.7T → 加速衰减，剩余 = (T–A) × 0.3 × exp(–2×(A–0.7T)/T)

为什么这样分段？ 前20%寿命基本无损耗，中间50%缓慢下降，最后30%急剧劣化，贴合机械电子设备实际。

🛠️ 状态修正 & 维修重置

  • 状态系数 S：正常1.0，异常0.7，损坏0.3，缺失0（直接失效）。
  • 维修重置：若部件在维修台账中有最近完工记录，则已用年限从该完工年算起，相当于“回春”。
  • 维修激励：每修一次额外增加1.5年（鼓励维护）。
部件剩余年限 rᵢ = max(0, 退化剩余 × Sᵢ) + 维修次数×1.5

这样，修过的部件剩余年限会明显回升，与“修了就年轻”的直观感受一致。

📌 数据不完整兜底：若某部件缺状态、缺修复年或缺种类，则按保守5年作为指导寿命，状态系数取1.0，不给予维修激励，并标记“待补采”。这既保证了不因缺数据而虚增寿命，也不至于直接剔除。

四、整栋剩余寿命的合成公式

步骤1： 计算每个部件的剩余年限 rᵢ（如上）。 步骤2： 计算结构短板 R_b min_r = min(所有参与部件的 rᵢ) // 最弱部件 部位加权平均 R_avg = Σ(部位权重 × 该部位内部件加权平均) 部位权重：加热0.30，散热0.26，自控0.26，主体0.18 R_b = 0.6 × min_r + 0.4 × R_avg // 短板主导 步骤3： 仍用现有BDRL反推整栋寿命 RUL_w（基于整栋健康分 h₀） 保留它作为宏观参考。 步骤4： 融合 RUL = α × RUL_w + (1–α) × R_b （α 推荐0.5，可调） 步骤5： 人工修正 RUL_final = RUL × K_man K_man：人工评价“好”→1.05，“中”→1.00，“差”→0.90 最终 clamp 到 [0, 12] 年。

为什么要融合BDRL？ 整栋健康分包含了人工评价、管护水平等综合信息，它与部件短板相互验证。α=0.5表示两者各占一半，当数据完备时逐步提高部件短板权重，数据缺失时回归BDRL。

假设某烤房建于2010年，当前2026年，健康分78。主要部件及修复情况如下表。 我们用升级算法计算整栋剩余寿命，并与旧BDRL对比。

计算结构短板 R_b： min_r = 0（大门） → 0.6×0 = 0 部位加权平均：加热8.7，散热6.5，自控7.0，主体(屋顶0.35+大门0)/2≈0.18 R_avg = 0.30×8.7 + 0.26×6.5 + 0.26×7.0 + 0.18×0.18 ≈ 6.56 R_b = 0.6×0 + 0.4×6.56 = 2.62 年 旧BDRL反推 RUL_w： 健康分78，房龄16年 → 按旧算法约 4.5 年（示例中未展开，但可算得）。 融合（α=0.5）： RUL = 0.5×4.5 + 0.5×2.62 = 3.56 年 人工评价“中”（K=1.0）→ RUL_final ≈ 3.6 年 预警等级：建议维修（0~4年），重点原因：大门损坏、屋顶老化。

六、与最新健康分算法的联动

健康分升级后已变为逐部件加权归一化（80%部件 + 10%管护 + 10%人工），且每个部件有独立的指导寿命、修复年份和状态。 寿命预测直接复用同一套部件台账，因此二者完全同步：

  • 健康分反映“当前综合健康程度”。
  • 剩余寿命反映“按当前状态还能用多久”。
  • 部件级别的健康和寿命一一对应，修了哪里，健康和寿命同时改善。
数据一致性：部件指导寿命表、状态判定、维修归类逻辑与健康分完全共用，避免口径冲突。

七、升级前后对比 & 给评委的一句话

升级前（BDRL）

  • 仅依赖整栋健康分反推
  • 掩盖短寿部件
  • 不能回答“先修哪”
  • 数据不全时无明确兜底

升级后（逐部件短板融合）

  • 每个部件独立计算剩余年限
  • 短板决定整栋下限
  • 明确风险部位排序
  • 数据不全按5年保守兜底

“寿命预测不再是整栋给一个平均答案，而是让每个部件用它的指导寿命和修复记录告诉我们还能用多久——最短的板决定了整栋的剩余寿命，修好短板，寿命自然延长。”
