为什么用"问卷＋画像"而不是简单统计平均分？

你已阅的《一份调查问卷引发的智与谋》已经把 35 道题的结构、以及"柏家坪村栽培维偏弱→要做栽培现场会"的用法讲清了。本算法要做的，是把这条经验模型化、可复算、可下钻：同一份问卷结果，既能算一张个人雷达图，也能上卷形成磅组、村、站的集体薄弱点，还能直接落到"上哪门课、派谁上门、先辅导谁"——给评委一条完整、量化的决策链。

第 1 步 数据从哪来：两份库 + 一套台账

① 问卷知识库（新采集）

700 户问卷共 35 题：23 道趣味知识答题覆盖栽培、植保、采烤(采收)、烘烤等 5 个知识维度；11 道针对烤房设施与管护需求的题（了解烟农最担心关注的管护困难）；其余为综合/属性题。答对给分、答错 0 分。

知识题 → 直接计入五维知识分；管护题 → 进"综合维"与管护需求画像；属性题 → 进烟农分级。

② 烟农台账库（现有）

复用项目已有烟农列表（前端 farmer.ts，对应 2026 烟农信息）：村/乡镇(area)、磅组(poundGroupName)、种烟年限(plantingYears)、种植面积(plantingArea)、累计烘烤炉次(totalBakes)、信用等级(creditLevel/creditScore)。这些字段补足问卷测不出的"熟练度与规模"。

③ 行为/实绩数据（可选，做修正项）

近三年烘烤实绩（上等烟比例、烤坏率）、服务评价与整改完成情况、培训到场率。本项目有此方向数据时叠加，增强画像的"真需求"。

五维知识维度与建议拆题（评职称可解释的定题依据）

维度维度含义问卷知识题示例基础权重 wd
栽培育苗、壮苗、移栽、田管与旺长调控最佳移栽密度？旺长期水肥如何管？0.18
植保主要病虫害识别、绿色防控、统防统治病毒病传播途径？生物药剂怎么用？0.18
采烤成熟度采收、编竿/上炕、部位烟分层下部叶适熟标准？编竿怎么分色号？0.19
烘烤温湿度曲线、定色转火、烤房设备操作湿球温度偏高怎么调？如何判断失水转火？0.25
综合管护制度、调剂/抢修流程、政策与信用集中管护怎么配合？报修走哪条通道？0.20

权重设计理由：烘烤直接决定烟叶商品性状与收益权重最高 0.25；采烤次之 0.19；综合维是平台落地能力（管护/调剂/政策）给 0.20；栽培、植保各 0.18。合计 = 1.00。若某维无题，可把该维权重按比例并入其他维（下钻时单独标记"本维样本不足"）。

第 2 步 问卷计分 → 五维标准化知识分

对第 p 位烟农、第 d 个维度： Kpd = (该维答对题数 ÷ 该维总题数) × 100 例：栽培维共 4 题，答对 3 → K栽培 = 3/4 × 100 = 75 村级第 d 维汇总：K̄村d = mean(该村所有作答烟农的 Kpd) 县级基准：md = mean(全县该维答对率)×100 // 0-100 连续分，满 100 表示该维全对
计分口径的两个约定（避免被问倒）
  • 答对即 1、答错即 0，不做歧义选项加权，保证可复算；
  • "不会/跳过"按错计（问卷知识题设计为必答，跳过视为未掌握），让"不知道"如实反映到低分；
  • 每户未填卷的维度不纳入村均值分母，避免有人漏答把整村拉低。

第 3 步 画像分合成与烟农分级（职业/普通/新手）

① 五维加权知识分：P知识 = Σd wd·Kd ② 修正画像分（可叠加行为修正项）： P = 0.60·P知识 + 0.15·P培训 + 0.15·P实绩 + 0.10·P评价 P_培训=到场×次数归一；P_实绩=上等烟占比/烤坏率修正；P_评价=服务整改率 ③ 烟农分级： P ≥ 85 且 种烟年限 ≥ 5 且 面积 ≥ 20 亩 → 职业烟农(示范引领) 60 ≤ P < 85 → 普通烟农(常规培育) P < 60 或 种烟年限 < 3 → 新手烟农(重点强补)

画像分 P 与健康分同是 0-100 尺度，风格统一，评委能一眼看出"同一套管理语言"。

为什么加修正项，而不是只看问卷？
  • 问卷有"会答与会用"的偏差——有人书面答得好但实烤稀烂（烤坏烟），用实绩项 0.15 校准"真本事"；
  • 培育要讲投入产出——知识薄弱但规模大的烟农许产许损，用规模/炉次放大其优先级；
  • 积分制可滚动——每次培训到场、复测提升都回流到 P_培训/P_评价，形成"培育闭环"。若暂无行为数据，可退化为 P=P知识（上方六三幺权重仅在有数据时启用）。

第 4 步（核心差异化） 薄弱缺口定位：把"弱"钉到站·村·磅组·个人

缺口定量（这是本算法的"差异化灵魂"）
村/磅组第 d 维缺口：Id = md县 − K̄d村/磅组 判定薄弱：K̄d < 60（明显不会）或 Id > 15（明显落后于全县） 薄弱优先级：Priority = 0.5×(100 − K̄d) + 0.3×φ规模 + 0.2×L承载 // φ规模=该村烟农户占比/炉次数；L=该村烤房负载率（复用新建模型） 最弱维度 WeakDim = mind(K̄d) → 用于定现场会主题

四级下钻：站 → 村 → 磅组 → 烟农

层级看什么产出
站该站各维均值 vs 全县该站下一年度培训大纲侧重
村村×五维矩阵红绿灯该村现场会主题 + 是否上门
磅组磅组内 weakest 维上门辅导名单 + 技术员指派
烟农个人五维雷达个人课程包 + 复测计划

红黄绿灯：绿=该维 ≥ 县均值；黄=低于县均值但 ≥ 60；红=低于县均值且 < 60 或缺口 > 15。

第 5 步 把画像变成可执行动作：上门辅导、现场会、课程与授信

入选：短板维 < 60 且 Priority 靠前 输出：烟农姓名·磅组·短板维·建议课程·技术员·上门日期·复盘复测日 跟随：种植年限 < 3 的新手 → 优先主教保；职业烟农 → 送"进阶小灶"

一句话：这页"烟农培育"和前面三页算法的关系（给评委的串联）

健康分告诉我们烤房好与坏（该修该换），发展指数告诉我们哪里缺烤房（该在哪建），烟农画像告诉我们谁、哪方面、在该怎么补课（谁来用、会不会用）——硬件（建/修）、软件（用/管）、人才（培育）三层在数据源上全部打通，统一 0-100 计分语言，形成"建—修—用—育"全链条闭环。

按你给的真实案例演算 磨坪·柏家坪村"栽培薄弱"全程跑一遍

案例环境（来自你的问卷结论）
磨坪站 · 柏家坪村（示例演算，题数/户数可按实替换） · 该村 15 户作答；栽培维 4 题 → 60 个作答格 · 实测答对 34 格 → K̄̂栽培 = 34/60 × 100 = 56.7 · 全县栽培均值 m栽培 = 72 · 缺口 I栽培 = 72 − 56.7 = 15.3 > 15 且 < 60 → 🔴栽培薄弱

该村栽培维即 WeakDim，下钻到磅组，筛选出 3 户栽培分 < 50 的新手户列入上门名单。结论与问卷原文一致：柏家坪村栽培偏弱 → 应针对性开展以栽培为主的现场会。

个人画像演算（示范户：张烟农）
张：栽培维 K=45，植保 K=70，采烤 K=60，烘烤 K=55，综合 K=80 P知识 = 0.18×45+0.18×70+0.19×60+0.25×55+0.20×80 = 8.1+12.6+11.4+13.75+16 = 61.85 分级：61.85 ∈ [60,85) 且年限≥3 → 普通烟农 短板：栽培 45 < 60，烘烤 55 < 60 → 建议"栽培+烘烤"小班＋上门 Priority = 0.5×(100−45) + 0.3×规模0.6 + 0.2×承载0.8 = 27.5+0.18+0.16 ≈ 27.8

上层村/站的 K̄ 即每位烟农 Kpd 的均值，个人→磅组→村→站逐级上卷，口径完全一致。
