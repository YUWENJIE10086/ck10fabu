总览 现有两套方法 + 一套融合提升

已有方法一 · 候选点选址（点位级，站点位合适度）

8大一级指标（烟田20/电力18/地形15/水文12/交通10/环境10/集群8/成本7）对每个候选点量化打分，AHP 主观 + 熵权客观 → 组合权重 → TOPSIS 排序，输出"高度适宜/适宜/一般/不适宜"。解决"这一块地适不适合盖烤房"。

已有方法二 · 村负载均衡推演（村级，考虑供求缺口）

村负载率 L = 村收购量(kg) ÷ (在用烤房数 × 单座产能5000kg)，县基准负载率对比得新建优先级指数，分级预警（>1.2红/橙/黄/绿/蓝），推演"新增 N 座后 L 降到多少"。解决"这个村到底还需要多少座"。

⚠️ 现有方法的短板（本次要补的三个维度）
  • 只看"产能够不够"（承载），没看"烤房好不好"（健康）——同样负载率1.0，全村健康分85和健康分40是两回事：健康分低的其实是"坏着在用"，该修该换而非只加数量；
  • 没看"明天还会不会增长"（发展）——规模稳定村与未来增10%/15%发展村，今天看着都不缺房，但后者的需求压力明显更大；
  • 两级脱节——村负载说"到底要几座"，点位说"这块地行不行"，两者没有在中国环节串成一个统一指数。

→ 因此本次以建议稿的"村级发展指数 = 健康50 + 承载30 + 发展20"为融合骨架，把上面三个短板全部纳入一个 0-100 指数，方向统一为分值越低越紧张、越需新建。

第 1 步（已有） 村级承载现状：村负载率与新建优先级

村负载率 L = 村年度实际收购量(kg) ÷ (村在用烤房数 × 单座设计产能) 县基准负载率 L̄ = 县总收购量(kg) ÷ (县在用烤房总数 × 单座设计产能) 新建优先级 P = L − L̄ // 相对全县平均越紧缺，P越大 建议新增数 need = max(0, ⌈L − 1.0⌉) // 把负载补到 1.0 以下
负载率 L等级色建议动作承载得分 g(L)
> 1.2严重超负荷🔴立即规划新建0.10
1.0 – 1.2超负荷🟠优先新建0.35
0.8 – 1.0饱和🟡可考虑新建0.60
0.6 – 0.8正常🟢暂不新建0.85
≤ 0.6富余🔵不新建，可调剂1.00

右列"承载得分 g(L)"为本次融合新增，供村级发展指数第2维使用——L 越高（烤房越挤）承载得分越低。现有系统已实现村负载率、县基准、优先级、分级预警、新增推演与"按村着色"（实测：全县在用1672座、县基准负载0.451、超负荷村3个）。

第 3 步（新增·核心） 村级发展指数 D： 健康50 + 承载30 + 发展20

主公式（0-100，分值越低越紧张、越需新建）
D村级发展指数 = 0.50·H健康 + 0.30·C承载 + 0.20·G发展 // 满分构成 = 50(健康) + 30(承载) + 20(发展)，方向完全统一：低分→新建

对应你建议稿"村级发展指数 = 健康平均分(50) + 承载平均分(30) + 发展因子(20)"，内部指标全部用本项目可得的真实数据落地。

① 健康因子 H（50分）

直接复用现有烤房健康分三维融合算法结果（已入库 ovens.health_score / kf_basedata.health_score_final）。

H = 50 × (该村在用烤房健康分均值 ÷ 100)

健康均分高 = 设备好 = 更"满足"，D 高、不急着新建；健康分低说明"坏着在用/老化待换"，D 低、该修该换。健康分天然的 0-100 尺度在这里直接当 50 分权重使用。

② 承载因子 C（30分）

由现有"村负载率 L"经分段映射"承载得分 g(L)"得到，见第1步右列。

C = 30 × g(L) L>1.2→0.10 │ 1.0-1.2→0.35 │ 0.8-1.0→0.60 │ 0.6-0.8→0.85 │ ≤0.6→1.00

L 越高承载越紧、C 越低、D 越低→越需新建。

③ 发展因子 G（20分）

面向"明天"的规模化需求（对应建议稿发展因子5项：集体经济/管护服务/政策/规模增长/发展承载量，数据可得前提下用政策、规模、承载压力三项代理）。

G = 20 × [ 0.55 + (0.15·P 政策) + (0.15·S 规模) − (0.15·Dl 压力) ] P/S/Dl 均归一化到 0-1

政策扶持多、规模增速稳的村，更有条件支撑新建；而未来增量大、现有闲置少（承载压力大）的村，则应把这部分"未来需求"体现为需要更多新建。

D 分级与新建建议（给决策用的硬规则）

村级发展指数 D状态色建议动作新建数
≥ 70发展充裕🟢无需新建，强化养护与调剂盘活0
55 – 70供需平衡🟡视健康分与未来计划按需少量新建ceil(L−1.0)₂₀
40 – 55发展趋紧🟠建议新建，优先落在"高度适宜/适宜"点位ceil(L−1.0)
< 40产能紧张🔴优先新建/扩容，且叠加发展预留ceil(L−1.0) + 预留
建议新建数（数量决策，融合现有 need 与未来增量）
基础补缺 need₀ = max(0, ⌈ L − 1.0 ⌉) 发展预留 need₁ = ⌈ (该村未来增速 r% × 明年收购量) ÷ 5000kg ⌉ // r 常取 10% / 15% 建议新建数 need = need₀ + need₁ （仅当 D < 55 时记入优先新建清单） // 目标：补差(现有负载降到1.0以下) + 预留(扛住未来10%/15%增产)

真实示例 两村对照，跑通村级发展指数

示例A · 磨坪·三墩岩村（现状宽裕 → 无需新建）
村负载率（真实接口） L = 0.664 → 等级"正常" 承载得分 g(0.664)=0.85 → C = 30×0.85 = 25.5 健康均分（示意，可按村聚合 ovens.health_score）H̄ = 76 健康因子 H = 50×0.76 = 38.0 发展因子 G = 13（示意，政策+规模中等、压力小） D = 38.0 + 25.5 + 13 = 76.5 → ≥70 发展充裕

✅ 结论：三墩岩村烤房够用、设备尚可 → 不需新建，重点是养护与调剂。已用真实村负载接口校准 L 值。

示例B · 某产能紧张村（现状缺房 → 建议新建）
村负载率 L = 1.30 → "严重超负荷" g(1.30)=0.10 → C = 30×0.10 = 3.0 健康均分 H̄ = 55 → H = 50×0.55 = 27.5 发展因子 G = 14（政策好但规模增速快、未来压力大） D = 27.5 + 3.0 + 14 = 44.5 → 40-55 发展趋紧 基础补缺 need₀ = ⌈1.30−1.0⌉ = 1 座 按 10% 增速发展预留：明年增量≈0.10×(1.30×在用×5000)kg ÷ 5000 ≈ 0.13×在用(座) 建议：新增 1 ~ 2 座，点位优先落在该村"高度适宜/适宜"候选点

✅ 结论：负载高 + 健康均值偏低 + 未来有增速 → 指数跌破 55，系统输出"建议新建 1~2 座"并给出落点点位。

两级串联逻辑（给评委的完整闭环）
村级发展指数 D（要建几座） → 候选点 TOPSIS 排序（建在哪） 每个需要新建的村，取其候选点中"高度适宜/适宜"且距烟田近的前 N 名 → 形成"新建清单" [村A 新建2座 → 候选点A1、A3] [村B 新建1座 → 候选点B5] … → 投入额 = Σ 座数 × 单座造价
