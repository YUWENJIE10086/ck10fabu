烤房健康分算法（最新口径，含数据不完整补充条款）

  • 三维 80/10/10：H=0.80×部件 + 0.10×管护 + 0.10×人工；
  • 部件内 4 部位加权 JR0.30/SR0.26/ZK0.26/ZT0.18，每部位内部“状态40/退化30/评价30”；

本次更新口径（建议终稿）

  • 部件层从“4 大部位宏观加权”细化到“逐部件：每个部件读自己的状态、修复年度、指导寿命”；

两者唯一差异在“部件内部怎么汇总”：现行=4 部位，终稿=逐部件+归一化。它们可通过同一套参考寿命表互相换算，落地时二选一实现即可，维度与总权重完全一致。

第 1 步 总公式（三维融合）

最终健康分 H = 0.80 × 部件归一化健康分 P_norm + 0.10 × 管护制度分 M + 0.10 × 人工评价分 E 部件归一化健康分： P_norm = Σ( 部件贡献分 Cᵢ ) / Σ( 参与部件权重 Wᵢ ) × 100 部件贡献分 Cᵢ = Wᵢ × Lᵢ(退化衰减) × Sᵢ(状态系数) 管护制度分 M：集中=100 · 分户=80 · 未知=80 人工评价分 E：好=100 · 中=80 · 差=50 · 未知=80

第 3 步 部件退化衰减 Lᵢ（CDCI 三段式）与状态系数 Sᵢ

退化分 Lᵢ —— CDCI 三段式

已用年限 Δt = 今年 − max( 部件修复年, 维修台账该组最近完工年 ) 无修复记录 → 按烤房建成年；仍缺 → 数据不全兜底(见第六节) 稳定区 Δt ≤ 0.2·Tᵢ → Lᵢ = 1.00 线性区 0.2Tᵢ < Δt ≤ 0.7Tᵢ → Lᵢ = 1 − k₁(Δt − 0.2Tᵢ), k₁=1/(0.5Tᵢ) 加速区 Δt > 0.7Tᵢ → Lᵢ = 0.30·e^(−k₂(Δt − 0.7Tᵢ)), k₂=2/Tᵢ

Lᵢ∈(0,1]，越逼近指导寿命末端衰减越快，贴合设备真实老化脚步；这也是寿命侧“还能用几年”的退火来源，两边同源。

状态修正系数 Sᵢ

部件状态Sᵢ说明
正常1.00按退化衰减完整计入
异常/老化0.70折减，保留修复潜力
损坏/损毁0.30可用性很低
缺失0.00不具备功能，贡献0
状态空（数据不全）1.00按5年兜底 + 标记待补采（第6节）
部件贡献 Cᵢ = Wᵢ × Lᵢ × Sᵢ P_norm = Σ(Cᵢ) / Σ(Wᵢ, 参与) × 100 H = 0.80 × P_norm + 0.10 × M + 0.10 × E

重点 · 补充条款 数据不完整时怎么办（正式口径）

总原则

缺数据的部件不剔除、也绝不虚高：能算的按真实年数算，算不了的按 5 年兜底并标记“待补采”，归一化后仍参与比较。这样既不会让缺采烤房只剩管护+人工两分，也不会让缺数据烤房被误判为老旧损坏。

编号数据缺失情形兜底处理标记
B1部件状态、修复年度、种类任一缺失该部件按“不完整档”：Tᵢ=5年、Sᵢ=1.00，Δt≤0.2×5 取 Lᵢ=1.0；仍占权重参与归一化待补采
B2修复年度缺失、但有建成年已用年限 Δt 按建成年真实计算，不强行置 0按建成
B3某部件记录整条缺失（表里没有该部件）该部件权重不进入有效权重分母 ΣWᵢ，用剩余有效部件归一化（不补分）归一
B4电源/发电机/烟夹无结构字段当前不纳入部件计算，占比自然转移到其余权重；补字段后按 5 年兜底纳入待补字段
B5整栋部件数据全部缺失部件分退化为中性分（取 70 或默认），仍与管护/人工融合，保证每栋有分兜底退化
B6管护制度未录入默认“集中管护”M=100 兜底（不因未知倒扣）默认
B7人工评价未录入默认“好”E=100 兜底，与现行一致默认
B8维修台账缺“已验收/完工日”不计入退化年龄重置（健康分不因未归档维修回弹）待归档
数据不完整部件（B1 口径）的具体代入 Tᵢ = 5； Aᵢ = 0； Δt = 0 → 稳定区 → Lᵢ = 1.00； Sᵢ = 1.00 Cᵢ(不完整) = Wᵢ × 1.00 × 1.00 = Wᵢ // 满寿命衰减、不虚增年份 归一化：P_norm = Σ溢(Cᵢ) / Σ溢有效Wᵢ × 100 缺状态≠缺部件：缺状态的仍占权重分母；缺部件的权重分母去掉。

“缺状态”和“缺部件记录”是两件事：有记录但状态空 → 按 5 年满衰减兜底并占权重；表里根本没有该部件 → 权重从分母剔除再用剩余归一。前者保守可信，后者干净不含糊。

这个示例的两层含义
  • 短寿部件自控(6年)逼近末端磨损 → 显著拉低健康分，且风险排序直指自控，与实物“自控最易坏”吻合；
  • 大门“状态空”按 5 年兜底给了满分衰减，没有因为缺状态就把它判成损坏拉低分，也不会因此虚高——它在归一化里拿回权重，标记《待补采》，补录真实修复年/状态后立即重算。

联动 维修台账的重置与归类（健康分回弹）

退化起始年 = max( 部件表修复年份 , 维修台账该部件组最近完工年份 ) 取“维修台账已验收/审核通过 且 end_date 非空”的记录 按 维修类型+维修描述关键词 归类到部件组： 加热(燃烧机/加热/送料) → 加热器 散热(散热管/热风/炉膛/灰门/烟囱) → 散热组 自控(自控/主板/探头/风机/电路) → 自控组 保温(屋顶/墙体/大门/挂烟梁) → 主体 无法归类 → 通用组 ALL（对部件整体加权） 通用组ALL 对整栋部件生效（等效重置整栋退化年龄）

与寿命侧共用同一套 computeRepairMap 归类逻辑；维修完工 → 部件 Δt 从维修完成年重算 → 退化衰减 回弹 → 健康分回升。修哪里，哪里的健康分就回春，投入可被直接看见。

排序 风险部件排序（谁拖累最多谁排最前）

满状态贡献 = Wᵢ 实际贡献 = Wᵢ × Lᵢ × Sᵢ 损失分 Gapᵢ = Wᵢ − 实际贡献 风险排序 = 按 Gapᵢ 从大到小 强化关键件：Riskᵢ = Gapᵢ × Kᵢ 建议 Kᵢ：自控1.25 · 加热1.15 · 散热1.15 · 大门/屋顶1.05 · 其它1.00

解释非常直接：不是说“自控仪看着重要”，而是它对 80 分部件总分造成的损失最大（Gap 最大）。维修人员翻开该栋烤房，Top3 就是最值得先下手的三处。
