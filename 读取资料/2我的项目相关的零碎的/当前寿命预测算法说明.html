烤房寿命预测算法说明

本文件梳理当前项目代码中已经存在的寿命预测算法，说明它们怎么预测、公式是什么、默认参数是什么、示例怎么算。 本次代码只修改健康分算法和风险排序，寿命预测算法暂不改动。

一、系统里现在有哪几类寿命算法

算法页面/接口核心思想结果字段
EDRL 指数衰减 /barn/health-algo/life-apply?algo=edrl 健康度随时间按指数曲线下降。 life_edrl
WRRL 威布尔可靠性 /barn/health-algo/life-apply?algo=wrrl 用可靠性工程的威布尔分布描述耗损失效。 life_wrrl
BDRL 双段退化 /barn/health-algo/life-apply?algo=bdrl 前期线性退化，后期加速劣化，并考虑维修延寿。 life_bdrl
GPLE 灰色预测 /barn/health-algo/life-apply?algo=gple 用健康分历史序列拟合趋势，适合少数据场景。 life_gple
最终版 BDRL /barn/health-algo/life-final-apply 读取 health_score_final，用健康分和物理房龄共同推算剩余寿命。 life_residual_final / current_life_residual / ovens.predicted_life_years

二、最终版 BDRL 当前怎么计算

当前前端“寿命预测算法”页面默认使用最终版 BDRL。它不是直接按烤房建成年份判死，而是读取最新健康分 health_score_final，再结合房龄判断剩余寿命。

输入： 当前年份 currentYear 建设/竣工年份 buildYear 物理房龄 age = currentYear - buildYear 当前健康分 h0 = kf_basedata.health_score_final，缺失时默认70 默认参数： Tc = 8 年，退化转折点 Hc = 60 分，转折点健康分 Tend = 12 年，理论寿命终点 H_min = 40 分，失效阈值 repairExtend = 2.5 年，估算维修延寿 维修次数： repairCount = floor(age / 8) TendAdj = Tend + repairCount × repairExtend

2.1 房龄在前段时

如果 age ≤ Tc： k1 = (100 - Hc) / Tc tEnd = (100 - H_min) / k1 residual = tEnd - age

2.2 房龄在后段时

如果 age > Tc： ratio = sqrt(1 - H_min / Hc) tEnd = Tc + ratio × (TendAdj - Tc) residual = tEnd - age

2.3 健康分回弹修正

理论健康分 theoreticalH： 若 age ≤ Tc： theoreticalH = 100 - k1 × age 若 age > Tc： theoreticalH = Hc × [1 - ((age - Tc) / (TendAdj - Tc))²] 如果实际健康分 h0 > theoreticalH： boostRatio = h0 / theoreticalH residual = residual × boostRatio 最终结果： RUL = clamp(residual, 0, 12)
解释： 如果一栋老烤房实际健康分比理论曲线高，系统认为它可能经历过维修或维护较好，因此按比例延长剩余寿命。 但最终上限锁定为 12 年，避免无限延寿。

三、最终版 BDRL 示例

假设当前年份为 2026 年，一栋烤房 2020 年竣工，健康分最终结果为 78 分。

age = 2026 - 2020 = 6年 Tc = 8，Hc = 60，H_min = 40 因为 age ≤ Tc，使用前段线性退化： k1 = (100 - 60) / 8 = 5 分/年 tEnd = (100 - 40) / 5 = 12 年 residual = 12 - 6 = 6 年 理论健康分： theoreticalH = 100 - 5 × 6 = 70 分 实际健康分 h0 = 78 分，高于理论健康分70： boostRatio = 78 / 70 = 1.114 residual = 6 × 1.114 = 6.68 年 最终剩余寿命 RUL = 6.7 年 预警等级：需关注

四、旧版四种寿命算法公式

EDRL 指数衰减

H(t) = H0 × e^(-λt) λ = -ln(H0 / 100) / age 剩余寿命 = [ln(H0) - ln(H_min)] / λ 默认： H_min=40 H_maint=60 policyMax=20

WRRL 威布尔可靠性

R(t) = e^(-(t/η)^β) H(t) = R(t) × 100 求 R(t)=R_min 时的 t 剩余寿命 = t - age 默认： η=25 β=2.5 R_min=0.4 R_maint=0.6

BDRL 双段退化

前段： H(t)=100-k1×t k1=(100-Hc)/Tc 后段： H(t)=Hc×[1-((t-Tc)/(Tend-Tc))²] 维修： Tend = Tend + 维修次数×ΔT

GPLE 灰色预测

若有健康分历史序列： 用 GM(1,1) 拟合退化趋势 若缺少历史序列： 按默认年退化率 degradeRate 推算 H(t) = h0 × (1 - degradeRate/100)^t 求 H(t) ≤ H_min 的时间

五、预警等级怎么判

剩余寿命预警等级业务含义
RUL > 7年正常常规巡检，不急于维修。
4 < RUL ≤ 7年需关注纳入年度跟踪，关注高风险部件。
0 < RUL ≤ 4年建议维修进入修复候选池，结合资金计划排序。
RUL ≤ 0年紧急维修需立即排查，必要时修复或退出。

六、当前算法的局限

当前最终版 BDRL 已经用健康分修正寿命，比单纯按建设年限更合理；但它还没有按“加热器、散热器、自控仪、烟夹、挂烟梁”等部位分别预测寿命。

后续如果你确认继续升级寿命预测，建议改成“整栋健康分反推寿命 + 各风险部位剩余寿命 + 关键短板约束”的组合模型。 这次按你的要求，暂时只改健康分，不改寿命预测。
