烤房寿命预测算法详解

基于烤房当前健康分与房龄，预测剩余使用寿命与维修预警时间。项目内置 4 种寿命算法（EDRL / WRRL / BDRL / GPLE），其中 BDRL 双段退化剩余寿命模型 为推荐算法，本页重点详解其原理、公式与实现。

算法：BDRL（推荐）
输入：健康分 + 房龄
输出：剩余寿命 + 维修预警
约束：政策最大年限

2BDRL 核心原理

双段退化思想

烤房健康度随使用年限的退化并非匀速，而是呈现 "先缓后急" 的形态：

  • 前段（0 ~ Tc）：线性退化期 —— 烤房投入使用初期，部件状态较好，健康度近似线性缓慢下降；
  • 后段（Tc ~ Tend）：加速劣化期 —— 越过转折点后，老化加速，健康度按二次曲线快速下滑；
  • 维修回弹效应 —— 每次大修使健康度回弹 ΔH，并延长自然寿命终点 ΔT。
// 两段退化曲线示意 H(t) = 100 - k₁·t // 前段：线性退化 (0 ≤ t ≤ Tc) H(t) = Hc·[1 - ((t-Tc)/(Tend-Tc))²] // 后段：加速劣化 (Tc < t ≤ Tend)

3详细计算公式

3.1 前段线性退化（0 ≤ t ≤ Tc）

k₁ = (100 - Hc) / Tc H(t) = 100 - k₁·t

k₁ 为前段退化速率，由起点健康度 100 与转折点 (Tc, Hc) 唯一确定。

3.2 后段加速劣化（Tc < t ≤ Tend）

H(t) = Hc·[1 - ((t - Tc) / (Tend - Tc))²]

后段采用二次抛物线形式，健康度从 Hc 加速下滑至 0（t = Tend 时 H = 0）。

3.3 维修回弹效应

repairCount = ⌊ age / 8 ⌋ // 简化：每 8 年计 1 次大修 Tendadj = Tend + repairCount × ΔT // 大修延长寿命终点

实际项目中按烤房房龄每满 8 年折算一次大修，每次大修使寿命终点延长 ΔT 年（默认 3 年）。

3.4 剩余寿命求解

// 前段：求解 H(t) = Hmin tend = (100 - Hmin) / k₁ // 后段：由 H(t) = Hc·[1 - ((t-Tc)/(Tendadj-Tc))²] = Hmin 反解 ratio = √(1 - Hmin / Hc) tend = Tc + ratio × (Tendadj - Tc) // 剩余寿命 Tres = tend - age

3.5 政策约束

Tresfinal = min( max(Tres, 0), max(PolicyMax - age, 0) )

最终剩余寿命取"算法结果"与"政策剩余年限"的较小值，且不小于 0，防止超龄烤房出现负值。

4计算示例

示例：某烤房房龄 17 年

参数：Tc=12，Hc=65，Tend=27，Hmin=40，Hmaint=55，PolicyMax=20

① 维修次数与寿命终点
repairCount = ⌊17/8⌋ = 2 Tendadj = 27 + 2×3 = 33
② 当前健康度（age=17 > Tc=12，走后段公式）
H(17) = 65 × [1 - ((17-12)/(33-12))²] = 65 × [1 - (5/21)²] = 65 × 0.9433 ≈ 61.3
③ 剩余寿命（求解 H(t) = 40）
ratio = √(1 - 40/65) = √0.3846 ≈ 0.6202 tend = 12 + 0.6202 × (33-12) = 12 + 13.02 = 25.02 Tres = 25.02 - 17 = 8.02 年
④ 维修预警（求解 H(t) = 55）
ratio = √(1 - 55/65) = √0.1538 ≈ 0.3922 twarn = 12 + 0.3922 × 21 = 20.24 Twarn = 20.24 - 17 = 3.24 年
⑤ 政策约束
政策剩余 = 20 - 17 = 3 年 Tresfinal = min(8.02, 3) = 3 年
结论：该烤房剩余寿命 3 年（受政策约束），约 3.24 年后健康度降至维修阈值，需提前安排维修。

7其他 3 种算法速览

EDRL 指数衰减剩余寿命模型

H(t) = H₀ × e-λ(t-t₀) λ = -ln(H₀/100) / t₀ Tres = (ln(H₀) - ln(Hmin)) / λ Twarn = (ln(H₀) - ln(Hmaint)) / λ

假设健康度按指数函数单调衰减，用当前健康分反推衰减率 λ，再外推至退役阈值。

WRRL 威布尔可靠性与剩余寿命模型

R(t) = e-(t/η)β tend = η × (-ln Rmin)1/β Tres = tend - age

形状参数 β 描述失效模式（β>1 为耗损失效），尺度参数 η 描述特征寿命，求解可靠度降至退役阈值 Rmin 的时间。

GPLE 灰色预测 GM(1,1) 寿命推演

X(1)(k) = Σ X(0)(i) // 一次累加 [a, b]T = (BTB)-1 BTY // 最小二乘参数 x̂(0)(k+1) = (1-e-a)·(x(0)(1) - b/a)·e-ak // 求 x̂(k) ≤ Hmin 的最小 k

利用 ≥3 期历史健康分序列做灰色预测外推，适合少数据贫信息场景。无历史数据时退化为按年退化率推算：H(t) = H₀×(1-r)(t-age)。
