烤房健康分算法详解

本系统采用多维度健康评价模型，从加热设备、散热器、自控设备、烤房主体、附属设施五大部件出发， 综合状态、时效、评价三维度量化烤房健康水平。当前系统采用增强型BMHI（最终版）作为正式健康分算法。

1增强型BMHI（最终版）— 当前正式算法
✅ 最终版 增强型烤房多维健康指数模型 Enhanced Barn Multi-dimensional Health Index
在基础BMHI框架上融合CDCI三段式退化函数：对加热设备(JR)、散热器(SR)、自控设备(ZK)、烤房主体(ZT) 四大部件，每个子部件按「状态分 × 退化分 × 评价分」三维量化，加权汇总得到0-100分健康指数。 结果存入 health_score_final 字段，并同步至烤房列表显示。
综合健康分 HealthScore = W_JR×C_JR + W_SR×C_SR + W_ZK×C_ZK + W_ZT×C_ZT 部件得分（每个子部件） C_i = α × S_status + β × S_degrade + γ × S_eval 状态分 S_status: 正常=100, 异常=50, 损坏=0 退化分（CDCI三段式退化函数） S_degrade(Δt) = 100 (Δt ≤ 0.2L, 稳定区) S_degrade(Δt) = 100 - k1×(Δt - 0.2L) (0.2L < Δt ≤ 0.7L, 线性区) S_degrade(Δt) = 30×e^(-k2×(Δt - 0.7L)) (Δt > 0.7L, 加速劣化区) k1 = 100/(0.5L), k2 = 2/L 评价分 S_eval: 较好=80, 一般=60, 较差=50, 差=30

2BMHI 烤房多维健康指数模型（基础版）
基础版 Barn Multi-dimensional Health Index AHP层次加权模型
采用层次分析法(AHP)确定5大部件权重，对每个部件的子部件进行「状态分×时效分×评价分」三维量化， 加权汇总得到0-100分的健康指数。包含附属设施(FS)部件，共5大部件。
综合健康分 BMHI = Σ(Wi × Ci), i = JR, SR, ZK, ZT, FS 部件得分 Ci = α × S_status + β × S_repair + γ × S_eval 状态分 S_status: 正常=100, 异常=50, 损坏=0 时效分（线性衰减） S_repair = max(0, 100 - Δt × k), Δt = 当前年份 - 修复年份 评价分 S_eval: 较好=80, 一般=60, 较差=50, 差=30

3CDCI 部件退化曲线积分健康度
推荐 Component Degradation Curve Integration 三段式退化函数模型
为每个子部件建立三段式退化函数：初期稳定→中期线性退化→后期加速劣化。 对曲线在当前时刻求值得到子部件瞬时健康度，再按部件层次加权汇总。 相比BMHI的线性衰减，CDCI更符合设备实际劣化规律。
三段式退化函数（L = 额定寿命） h(Δt) = 100 (Δt ≤ 0.2L, 稳定区) h(Δt) = 100 - k1×(Δt - 0.2L) (0.2L < Δt ≤ 0.7L, 线性区) h(Δt) = 30×e^(-k2×(Δt - 0.7L)) (Δt > 0.7L, 加速劣化区) k1 = 100/(0.5L), k2 = 2/L 子部件修正 h' = h × 状态修正 × 评价修正 状态修正: 正常×1.0, 异常×0.5, 损坏×0.2 评价修正: evalScore / 80 综合得分 CDCI = Σ(Wi × Ci)，FS特殊处理: wFs × (fsScore/100 × 50)

4其他对比算法
FCHE 模糊综合健康评价模型 Fuzzy Comprehensive Health Evaluation
评价集 V = {优(≥90), 良(75-90), 中(60-75), 差(<60)} 隶属度函数（以Δt为例） μ优 = max(0, 1 - Δt/5) μ良 = max(0, 1 - |Δt-5|/5) 模糊变换（加权平均型） B = A ∘ R 去模糊化 Score = Σ(bk×vk) / Σbk
📐 计算示例
JR(Δt=4, 较好): μ = (0.30, 0.50, 0.20, 0.00)
ZT(door Δt=17, 较差): μ = (0.00, 0.05, 0.25, 0.70)
B = (0.1525, 0.4125, 0.2750, 0.1600)
Score = (0.1525×90 + 0.4125×80 + 0.275×65 + 0.16×40) = 71.0
TOPSIS 熵权-TOPSIS健康排序法 Entropy-TOPSIS Health Ranking
标准化 pij = xij / Σxi 熵值 Ej = -(1/ln n) × Σ(pij × ln(pij)) 熵权 Wj = (1 - Ej) / Σ(1 - Ej) 相对贴近度 Ci = Di- / (Di+ + Di-) × 100
利用信息熵计算各指标客观权重（数据越分散权重越大），再用TOPSIS法计算每栋烤房与理想最优解和最劣解的相对贴近度， 实现多烤房横向排序。权重由数据自动计算，无需人工设定。
CRHE 组合赋权融合健康度 Combined Ratio Hybrid Evaluation
组合权重（AHP主观 × 熵权客观） Wj = (W_ahp_j × W_entropy_j) / Σ(W_ahp × W_entropy) 综合得分 CRHE = Σ(Wj × Ci)
将AHP主观权重与信息熵客观权重通过乘法合成，既尊重专家经验又反映数据分布。AHP权重：JR=0.25, SR=0.20, ZK=0.25, ZT=0.20, FS=0.10。
5算法数据流
数据输入 kf_basedata（烤房基础信息：project_id, finish_date, use_status） → kf_heater（加热设备 JR：burner_status, burner_repair_year, evaluation） → kf_radiator（散热器 SR：pipe/furnace/ash_door/chimney 的 status + repair_year） → kf_controller（自控设备 ZK：8个子部件的 status + repair_year） → kf_oven_body（烤房主体 ZT：wall_roof/beam/door 的 status + repair_year） 算法执行 POST /barn/health-algo/final-apply → 增强型BMHI计算 → 存入 health_score_final 结果同步 health_score_final → current_health_score（烤房列表显示） health_score_final → ovens.health_score + ovens.health_level（小程序共用）
