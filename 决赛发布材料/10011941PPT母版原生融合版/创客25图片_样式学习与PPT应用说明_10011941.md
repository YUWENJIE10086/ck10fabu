# 创客25图片：401张逐图样式学习与《智烤管家》应用说明（10011941）

> 说明：`创客25图片.zip` 实际解压得到 **401 张**比赛/演示截图。逐图索引见同目录 CSV；本说明按视觉语言聚类总结，但 CSV 中每一张图都对应了“样式类别—学到什么—应用到哪一页”。

## 一、这批优秀比赛PPT最稳定的视觉规律

1. **一页只讲一个观点**：舞台远距阅读优先，标题比正文更重要。
2. **深蓝为场，青蓝为骨，黄色只点题，红色只预警**：避免五颜六色。
3. **三步法是技术页最常用结构**：输入/方法/输出，编号圆点+功能胶囊+箭头。
4. **截图必须“套进叙事”**：截图不是裸贴，而是和流程、标注线、结论一起出现。
5. **成效页用大数字，不用段落**：数字大、解释小，4～6个硬指标足够。
6. **高级感来自留白和层级，不来自更多装饰**：背景持续统一，组件重复使用形成记忆。

## 二、12类样式逐类学习及落点

### C0｜轻色产品界面+实机/手机实景（9张）
- **学到的样式：** 白/浅色产品UI作为证据主体，配手机或实景外壳；不做大面积装饰。
- **用到本PPT：** S6一库见底、S10智用：真实小程序/报修界面放进深蓝母版；只把UI当证据，不改变母版。

### C1｜竖屏录屏/手机截图（65张）
- **学到的样式：** 竖屏信息密度高，适合做素材而非整页版式；应裁切关键区域。
- **用到本PPT：** 未直接套版；只借鉴“手机界面只露关键步骤”，用于S6、S10。

### C2｜蓝色舞台框+浅色证据卡（17张）
- **学到的样式：** 深蓝背景中嵌一张高亮白/浅卡，视觉中心清晰，外围少量标签。
- **用到本PPT：** S7模型①、S12智管：后台截图集中为一个证据区，左侧保留三步法。

### C3｜现场大屏单中心构图（38张）
- **学到的样式：** 远距离可读：一页一个中心观点，大标题+一个主图/主流程，文字极少。
- **用到本PPT：** S3根因、S9视频转场、S15结尾：只留一句核心判断。

### C4｜深蓝科技三步流（54张）
- **学到的样式：** 青蓝发光线、编号圆点、三步纵向/横向流程、少量绿色/青色功能胶囊。
- **用到本PPT：** S6一库、S7模型①、S8模型②、S10智用、S12智管：统一三步法。

### C5｜数据驾驶舱/地图看板（30张）
- **学到的样式：** 整页或半页大屏数据图，强调地图、指标、趋势，外围不堆文字。
- **用到本PPT：** S8模型②右侧沙盘、S11智投四屏驾驶舱。

### C6｜蓝色证据页+大白卡（40张）
- **学到的样式：** 一侧深蓝逻辑，一侧大面积白色后台/证书/公式；证据比装饰更重要。
- **用到本PPT：** S7模型①右侧管理后台、S12智管右侧工单/档案。

### C7｜竖屏实拍/录像界面（29张）
- **学到的样式：** 更偏过程记录和实拍，不适合作为决赛主版式。
- **用到本PPT：** 不直接使用；仅借鉴“关键操作截图+标注线”方法。

### C8｜比赛舞台超简洁页（31张）
- **学到的样式：** 标题大、图形少、核心词大；舞台远距识别优先。
- **用到本PPT：** S1封面、S2三痛点、S9视频、S15收口。

### C9｜深蓝模块化流程/环形图（42张）
- **学到的样式：** 模块框、箭头、环形关系、亮青边框；复杂内容被压成模块。
- **用到本PPT：** S4“1234”、S5总体蓝图、S14创新双栏。

### C10｜蓝青高质感组件页（43张）
- **学到的样式：** 蓝青渐变框、玻璃态卡片、发光描边、黄字小题签、白/青大标题。
- **用到本PPT：** S2三痛点直接复用原生组件；S4方案卡、S9转场框、S13成效卡统一风格。

### C11｜办公屏幕/Excel实拍（3张）
- **学到的样式：** 信息真实但视觉噪声大，适合备份证据，不适合主舞台。
- **用到本PPT：** 不用于主PPT；只保留后台真实截图作为可信度证据。

## 三、用户给出的三张强约束样式

- **青蓝渐变圆角玻璃框**：作为三痛点/方案/视频转场的主容器，不再自己造彩色卡片。
- **黄色小题签**：只用于“第一‘忧’/第二‘忧’/第三‘忧’、阶段编号和关键提示。
- **白→青渐变大字**：直接沿用3S原生文本的 `gradFill`，用于三痛点大词、封面/结尾/关键转场；不是用普通蓝色字替代。

## 四、最终PPT逐页采用的样式来源

- **S1 封面**：3S S1封面构图 + S3白青渐变字 + 创客25 C8大屏极简；标题、项目副题、1234一句话；其余留白。
- **S2 三个难题**：**直接复用3S S3原生可编辑卡片**；黄色小题签 + 白青渐变大字 + 青蓝玻璃框。
- **S3 三愁根因**：3S S4三角关系图 + C3舞台单中心；三条断链：资源/管护/投入。
- **S4 1234方案**：3S S5三张渐变卡 + C9模块化；一库/双模/三智三卡，四队作为底部机制。
- **S5 总体蓝图**：3S S6原生复杂架构；数据—模型—平台—机制；保留母版的架构表达。
- **S6 一库见底**：3S S7三步法 + C0手机证据；现场采集→标准判定→一房一档。
- **S7 模型①**：3S S9三步法 + C2/C6后台证据；12部件→AHP+Weibull→健康/寿命/风险/优先序。
- **S8 模型②**：3S S13三步法 + C5沙盘看板；有效烤能→AHP+熵权→TOPSIS+情景沙盘。
- **S9 视频转场**：3S S14大留白 + S3渐变大字；仅保留问题和“视频约1分钟”。
- **S10 智用**：3S S10手机双屏 + C4三步流程；预约调剂/一键报修/评价回写。
- **S11 智投**：3S S15四屏看板 + C5驾驶舱；存量、增量、选址、效果。
- **S12 智管+四队**：3S S12三步法 + C6后台证据；四队→流程闭环→机制长效。
- **S13 成效**：3S S11大数字卡 + C8大屏识别；2442、340+、48/18、0.38h/96.8%、1363/81%、190万。
- **S14 创新**：3S S16双栏创新框 + C9模块化；业务闭环 + 技术耦合。
- **S15 收口**：3S S17结尾 + S3渐变大字；让数据说话，让模型决策，让管家落地。
